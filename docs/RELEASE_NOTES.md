# 0.1.0

伺服系统参数辨识与控制优化桌面平台，基于 PyQt5 和 MATLAB/Simulink。

- 中英文界面，6 种辨识、6 种单目标和 4 种多目标算法。
- 参数校验、收敛与跟踪曲线、计算计时及停止控制。
- 运行日志、历史记录、归档与自动清理。
- 环境安装脚本、计算示例和参考结果。
- 原创 Python 代码采用 GPLv3；第三方材料保留原有条款。

运行环境：Windows x64、MATLAB R2024b、Simulink 和 Motor Control Blockset。

## English

A PyQt5 and MATLAB/Simulink desktop platform for servo identification and controller optimization.

This version includes bilingual interfaces, 16 algorithm entry points, input validation, convergence and tracking plots, run controls, logs, history and retention settings. Setup scripts and a PSO/ISE example are included. Original Python code is licensed under GPLv3; third-party materials retain their own terms.

Requires Windows x64, MATLAB R2024b, Simulink and Motor Control Blockset.
