# 使用指南

## 快速启动

已配置好环境的电脑，直接双击根目录的 **[start_ui.bat](../start_ui.bat)**。也可在 VS Code 中打开本项目，在终端执行：

```powershell
.\start_ui.bat
```

1. 在登录界面右上角选择 **中文 / English**。
2. 演示账号和密码均为 **111**，可点击按钮或按回车登录。
3. 选择辨识或优化模式、算法和参数，再点击“运行算法”。

密码默认隐藏，点击输入框右侧的眼睛图标可显示或隐藏。按 Tab 可依次切换输入框及控件；登录失败后，关闭提示会选中需要修改的输入内容，便于重新输入。

语言选择会立即更新登录页面，登录后沿用到主界面。下次启动会恢复上次选择；需要再次切换时，在登录页面调整即可。算法缩写、默认参数和计算逻辑不受语言影响。语言偏好保存在当前 Windows 用户的配置目录，不保存登录密码。

启动入口固定使用项目自己的 Python 和独立 `.venv`，先检查依赖版本、MATLAB Engine、MATLAB 安装及模型文件。检查失败时显示原因并停止，不回退到系统 Python。检查记录位于 `runtime/startup/`。

MATLAB 会在点击“运行算法”后自动启动。打开登录界面不会启动 MATLAB，也不会验证许可证；实际计算仍需要有效授权。演示登录仅用于进入界面，不提供用户身份认证或权限管理。

## 首次安装与运行环境

当前安装与进程管理面向 **Windows 64 位**。先安装并完成授权：

- MATLAB **R2024b**；
- Simulink；
- Motor Control Blockset；
- Parallel Computing Toolbox 可用于多目标并行计算；不可用时按现有逻辑顺序计算。

本项目调用完整 MATLAB，MATLAB Runtime 不能替代它。当前电脑已验证的主要版本如下：

| 组件 | 版本 |
| --- | --- |
| MATLAB / Simulink | R2024b Update 6 |
| MATLAB Engine for Python | 24.2.2 |
| Python | 3.12.14，64 位 |
| PyQt5 / Qt | 5.15.11 / 5.15.2 |
| NumPy / SciPy / Matplotlib | 2.0.2 / 1.13.1 / 3.9.4 |

在尚未建立环境的新项目目录中执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\setup_environment.ps1
.\start_ui.bat --check
```

安装过程需要联网下载固定版本的 Python、安装工具和依赖，并校验下载文件。基础 Python 安装在项目 `.python/`，运行依赖安装在 `.venv/`；脚本不修改系统 Python 或系统 PATH。已有合格环境会直接通过检查；不合格或未完成的已有环境会报告问题，不会被覆盖。

不要直接复制 `.venv` 到另一台电脑或另一条路径。移动项目后，应保留旧环境并在新位置重建。日常使用 `start_ui.bat`，无需手动激活虚拟环境，也无需执行全局 `python` 或 `login` 命令。详细维护与恢复步骤见 [环境说明](../docs/环境与维护.md)。

## 计算时限与停止

| 界面项目 | 含义 |
| --- | --- |
| 最大迭代次数 | 算法计划执行的迭代次数；正常完成后结束计算 |
| 最长计算 / Time limit | 从算法开始计算时计时；默认 **240 分钟**，运行前可设置为 **1–1440 分钟** |
| 计算耗时 / Compute | 仅统计算法计算阶段；开始停止或清理资源时停止累计 |
| 总耗时 / Total | 包含 MATLAB 启动、算法计算和退出清理的全部耗时 |

达到最长计算时间会**触发停止流程**。MATLAB 启动与资源清理使用独立的保护时限，停止和进程退出也需要时间，因此总耗时可能大于设置的计算时限。

运行中可点击“停止计算”。界面会等待本次资源清理完成后恢复操作。关闭正在计算的窗口时，可选择继续运行，或停止并关闭。停止、超时或失败的任务不会显示为完整成功结果；调整参数或处理错误后，可点击“重新运行”。

所有算法在每次迭代完成后发布收敛数据，界面约每秒刷新一次；较快的迭代可能合并显示。初始化及第一次仿真尚未完成时，迭代数仍为 0。达到时限后先显示“正在停止并清理资源”，退出完成后才显示已停止。验证范围见 [验证说明](../docs/validation.md)。

主窗口可随屏幕大小缩放。较窄窗口自动将参数控制区放在图表上方，空间不足时可滚动查看完整内容；宽屏保持左右排列。

## 运行数据与日志

数据写入以下目录，每次运行使用独立的时间戳与标识：

```text
runtime/identification/<run-id>/
runtime/optimization/<run-id>/
```

| 文件 | 内容 |
| --- | --- |
| `request.json` | 算法、输入参数、界面语言与运行目录 |
| `run_state.json` | 最近一次运行状态、时限、进程标识、计算耗时与总耗时 |
| `*_temp_data.mat` | 算法保存的收敛数据 |
| `result.npz` | 计算进程返回的结果，需通过界面侧校验后才显示为成功 |
| `matlab.log` / `process.log` | MATLAB 输出与计算进程诊断信息 |
| `error.log` / `supervisor_error.log` | 出现相应异常时记录的错误详情 |

文件按运行阶段产生，提前停止或启动失败时可能只有部分文件。点击“查看日志 / Open logs”可打开当前任务目录。MATLAB 和操作系统的原始报错保留来源语言。

主窗口右下角的“运行记录 / Run history”可查看历史参数、状态和已有结果，打开对应目录，或将整次运行归档。归档表示禁止自动删除，并非另建备份；需要对外分享或独立备份时仍应复制对应目录。旧记录没有计算阶段耗时时会显示“—”。

自动清理默认开启：在主窗口打开后、每小时及一次运行结束后检查，保留最近 **30 天**的记录，并额外保护最新 **20 次未归档的已结束运行**。已归档、未结束、元数据不完整的记录不会自动删除。已结束且未归档的运行超过 **7 天**后，可清理其 `slprj/` 和 `*.slxc` 仿真缓存，保留结果、收敛数据和日志。

在记录窗口可关闭自动清理，或修改保留天数（7–3650 天）；“按规则清理”会保存当前设置并立即执行同一规则，不会清空全部记录。策略保存在 `runtime/retention.json`，最近一次清理摘要保存在 `runtime/last_cleanup.json`。仅管理上述两类运行目录下可识别的记录，不递归删除历史测试报告、未知目录、链接或联接目录。

`runtime/` 不纳入 Git。这些记录不提供完整实验版本管理或断点续算。
