# 项目背景与作者分工

**AI助力工业控制智能化** 是西交利物浦大学参加第四届高校电气电子工程创新大赛的团队作品，获得 **2025 年全国赛一等奖**。

**Yuchen Wang（王雨晨）负责 UI 界面与数据管理模块**，包括界面交互、算法配置、MATLAB/Simulink 调用、结果可视化与运行记录。项目将参数辨识和控制优化过程组织为可操作、可查看结果的桌面工作流程。

完整参赛项目还包括电机建模、智能优化算法研究、EAE–MATLAB 通信和 Lexium 18 硬件验证，由团队共同完成。本仓库提供界面源码、相关算法与仿真模型，并保留原有作者说明和第三方来源。

## English

**AI for Intelligent Industrial Control** was a team project at Xi'an Jiaotong–Liverpool University. It received a **national first prize in the 2025 fourth university electrical and electronic engineering innovation competition**.

**Yuchen Wang developed the UI and data-management component**, covering interface interaction, algorithm configuration, MATLAB/Simulink integration, visualization and run records. The wider team worked on motor modelling, optimization research, EAE–MATLAB communication and Lexium 18 hardware validation.

This repository shares the interface, associated algorithms and simulation models, with original author attribution and third-party notices retained.
