# 环境与维护

## 安装要求

本项目的启动和进程管理面向 Windows 64 位。使用完整 MATLAB R2024b、Simulink 和 Motor Control Blockset，并在 MATLAB 桌面完成账号授权。多目标算法可使用 Parallel Computing Toolbox；不可用时使用已有串行分支。

项目使用 Python 3.12.14、MATLAB Engine 24.2.2、PyQt5 5.15.11。依赖版本和文件哈希分别固定在 `requirements*.txt` 与 `requirements*.lock`。MATLAB 安装位置由注册表及 Engine 配置识别，无需安装在开发者使用的盘符。MATLAB Runtime 不能代替完整 MATLAB。

Python 3.12 与 R2024b 的版本兼容性见 [MathWorks 说明](https://www.mathworks.com/support/requirements/python-compatibility.html)。Python 运行时来自 [Astral 的托管 CPython 构建](https://docs.astral.sh/uv/concepts/python-versions/#managed-python-distributions)，工具版本、下载地址和校验值在 `tools/bootstrap.json`。

## 新目录安装

在仓库根目录的 PowerShell 中执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\setup_environment.ps1
.\start_ui.bat --check
.\start_ui.bat
```

安装脚本先核对 MATLAB，再下载并校验安装工具、建立 `.python/` 与 `.venv/`、安装固定依赖，最后检查导入位置和模型文件。它不改变系统 Python 或系统 PATH。已有合格环境只进行检查；不合格的已有环境不会被覆盖。

安装需要能够访问 GitHub、Python 包索引和 Python 构建下载服务。网络失败时保留完整报错，排除下载问题后在新的干净目录重试；不要绕过哈希校验。

## 日常启动与迁移

日常双击 `start_ui.bat` 即可，无需激活虚拟环境。VS Code 用户也可在项目终端运行同一个入口。启动失败时，提示及 `runtime/startup/last_check.json` 会指出依赖、路径或模型问题。

不要将 `.venv/` 或 `.python/` 复制到另一台电脑或另一条路径后继续使用。需要移动时，先另行保存运行结果，再在新克隆的源码目录运行安装脚本。旧环境保留到新环境验证通过，避免直接覆盖。

## 验证与排错

以下检查不进行 MATLAB 仿真：

```powershell
.\start_ui.bat --check
.\.venv\Scripts\python.exe -I -X utf8 tests\smoke_ui.py
.\.venv\Scripts\python.exe -I -X utf8 -m unittest discover -s tests -p "test_*.py"
```

启动检查能够验证环境隔离、固定依赖、MATLAB 安装和模型文件，但不会占用许可证。是否有可用许可证需通过一次真实计算确认。可运行 [PSO / ISE 示例](../examples/pso_ise/README.md)，或在界面用小种群、少量迭代验证。

若出现授权报错，先从 MATLAB 桌面确认登录和授权状态；本项目不修改或绕过 MathWorks 授权。若工具箱缺失，补齐相应 MATLAB 组件后再重试。

## 数据与维护

每次计算写入独立的 `runtime/identification/` 或 `runtime/optimization/` 子目录。界面的“查看日志”可打开本次目录。优先查看 `run_state.json`、`matlab.log` 及错误日志；`request.json` 和 `result.npz` 保存本次请求与结果。

“运行记录”窗口提供查询、归档和保留策略。默认保留最近 30 天，另保护最新 20 次未归档的已结束运行。已归档、未结束或无法识别的记录不自动删除。归档是保留标记，不是独立备份；重要实验仍应另行复制保存。

达到计算时限后先停止并清理本次 MATLAB 进程，再恢复界面操作。计时区分计算耗时与包含启动、退出的总耗时。不要按进程名批量结束 MATLAB，以免影响自己的其他会话。

验证范围与当前局限见 [validation.md](validation.md)。
